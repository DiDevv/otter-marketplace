# Otter Marketplace

A small Claude Code plugin marketplace with skills that streamline my day-to-day engineering work.

## Install

```
/plugin marketplace add DiDevv/otter-marketplace
/plugin install otter-skills@otter-marketplace
```

## Plugins

### otter-skills

| Skill | What it does |
|-------|--------------|
| `code-best-practices` | Guides Claude through a clean-code workflow: explore, code, test, adversarial review, document, and commit with Conventional Commits. |
